# Problem Statement - Current Documentation Position

FlowGuard responds to an industrial asset and manpower monitoring problem statement where separate manual workflows can make access checks, attendance, unattended-object monitoring, loading-bay coordination, security review and tenant support harder to supervise.

## Project Goals

- Designed to support the project goal of reducing repetitive manual monitoring.
- Improve visibility across access, assets and logistics.
- Preserve human review for security decisions.
- Demonstrate a proof of concept that combines facial access management, object and zone monitoring, Smart Logistics, and AI Helpdesk/Incident Support.

## Current Proof-of-Concept Scope

- Facial enrolment and recognition with motion-liveness head-turn verification.
- Gate Scanner Attendance IN/OUT and V-Patrol access-event logging.
- Camera inventory, monitoring zones, unattended-object thresholds and DetectionAlert review.
- Booking creation, Bay A/B scheduling, Driver Pass, gate arrival/completion and mock-safe WhatsApp notifications.
- Chat transcripts, support-ticket escalation, knowledge base and incident-resolution notes.

## Limitations

Targets from the original brief are treated as goals, not measured outcomes. The current merged repository does not document production deployment, production sensor telemetry, PPE enforcement, pest detection, HVAC control, robotics monitoring or guaranteed operational launch as implemented features.
